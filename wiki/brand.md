### 2.2 배경별 로고 사용 (2.3 ~ 2.4)

- 지정 배경 컬러: **Sub Blue 6 / Sub Blue 5 / B Blue / B Navy 2 / B Gray / Sub Gray 7**
- 규정 배경 컬러 외에서 로고가 필요하면 **흑백 로고**를 쓴다.
- 배경 명도 K10~K100 구간별 로고 사용 규정을 따라 가시성을 확보한다.

### 2.3 최소 여백 · 최소 크기 (2.5)

| 항목 | 값 |
|---|---|
| 최소 여백 (Isolation Area) | 상하좌우 **1.1X** (X = 로고 심볼 기준 단위) |
| 최소 크기 — 인쇄 | **5 mm** |
| 최소 크기 — 화면 | **16 px** |
| 최대 크기 | 정비례 유지 시 제한 없음 |

### 2.4 디지털용 로고 크기 (5.6)

| 대지 | 로고 크기 |
|---|---|
| 1000 × 1000 px | 46 ~ 107 px |
| 1920 × 1080 px | 40 ~ 150 px |

### 2.5 인쇄용 로고 크기 (5.4)

| 판형 | BI | CI |
|---|---|---|
| A4 (210×297) / **A5 (148×210)** | **32 mm** | **13.5 mm** |
| A3 (297×420) | 23 mm | 9.3 mm |
| A2 (420×594) | 16 mm | 6.7 mm |
| A1 (594×841) | 12 mm | 4.7 mm |

### 2.6 BI–CI 병기 (5.1 ~ 5.2)

- CI 높이는 BI 기준 **0.3X ~ 0.6X**
- 배치 3종: **사선 배치**(BI 좌·우측 상단 / CI 좌·우측 하단), **상·하단 배치**, **측면 배치**

### 2.7 브랜드 텍스트 표기 (2.6)

- `B`는 **반드시 대문자**
- 서브 브랜드 영문은 **반드시 소문자**
- B와 서브 브랜드 사이 **반드시 띄어쓰기**

| 올바름 | 틀림 |
|---|---|
| `B direct shop` | `Bdirect shop`, `b direct shop`, `B DIRECT SHOP`, `B direct샵`, `B 다이렉트 shop` |

국문 표기(`B다이렉트샵`)는 영문 사용 불가 시 극히 제한적으로, Brand Comm팀 사전 협의 후.

### 2.8 제휴 로고 (2.7)

파트너사 로고 크기는 형태에 따라 다르므로 **반드시 BX팀 협의 후 진행**. (Primary 0.33x~0.56x / Secondary 0.53x 기준)

## 3. 타이포그래피

### 3.1 전용 서체 (4.1 ~ 4.3)

| 서체 | 용도 | 웨이트 |
|---|---|---|
| **SKT Sans 제목체** | 제목용 | ExtraLight · Light · Regular · SemiBold · Bold · ExtraBold |
| **SKT Sans 본문체** | 본문용 | Light · Regular · SemiBold · Bold · ExtraBold |

전용 서체를 **우선으로 사용**해야 하며, 다른 서체가 필요하면 유관부서 협의.
→ 웹 도구에서는 **폰트 교체 UI를 제공하지 않는다.**

### 3.2 자간 · 행간 · 정렬 (4.4 ~ 4.5)

금지 항목:

- 가독이 어려운 **넓은 행간** 사용 금지
- 가독이 어려운 **좁은 행간** 사용 금지
- 가독이 어려운 **좁은 자간** 사용 금지
- 내용 전달을 방해하는 **정렬 변형 지양**

## 5. 그래픽 시스템 (6.0)

브랜드 강조 ← → 콘텐츠 강조 순의 4단계 매트릭스.

| 단계 | 그래픽 | 성격 |
|---|---|---|
| A | **Logo** | 로고를 강조해 브랜드에 집중. 메인 로고 + 메인 컬러 중심, 추가 그래픽·서브 컬러 사용 제한 |
| B | **Logo Variation** | 로고 크롭 / T-B 패턴. 볼드한 인상. **같은 면에 로고를 추가 배치하지 않는다** |
| C | **Motif** | 로고를 해체한 기하 요소 (Human / Open / Tech). 기본 · 텍스트 프레임 · 패턴 3유형 |
| D | **Contents Frame** | 사선 / 사각 / 원 프레임. 콘텐츠와 융합 |

### 5.1 Graphic B — 로고 크롭 금지 규정 (6.5)

- 임의 회전 크롭 금지 · 규정 외 임의 확대 크롭 금지
- **로고 상단 영역 크롭 금지** · 하단 크롭된 부분 노출 금지
- 좌우 반전 금지 · 좌우 여백 다르게 사용 금지
- T-B 패턴 내 B 로고 최소 높이: **18 px / 3 mm** (T-B 공동 산출물에만 제한 사용)

### 5.2 Graphic C — 모티프 (6.8 ~ 6.11)

- 기본형은 **반드시 B 로고와 함께** 사용. 확장은 좌측으로, 정원 기준 **0.2X 간격**
- 텍스트 프레임 금지: 사선 도형 중복 사용 지양 / 도형 높이값 변경 금지 / 사선 도형 안쪽에 텍스트·오브젝트 금지 / 사선 도형 확장 금지 / 도형 안 텍스트 줄바꿈 금지 / 간격 임의 변형 금지
- 패턴 내 정원 최소 높이: **37 px / 10 mm**

### 5.3 Graphic D — 콘텐츠 프레임 (6.12 ~ 6.18)

| 프레임 | 규정 |
|---|---|
| **사선(Diagonal)** | 각도 **-160° 우선**. 상황에 따라 -153.5°(로고 각도) 또는 -170° 사용 가능. **-153.5° ~ -170° 범위를 벗어나는 각도 사용 금지.** 세로형 최소 높이 대지 세로면 기준 0.05X, 가로형 최소 넓이 대지 가로면 기준 0.1X |
| **사각(Square)** | 세로형 최소 높이 0.3X, 가로형 최소 넓이 0.3X |
| **원(Circle)** | 최소 크기 0.3X. 확장형의 정원 넓이는 대지 짧은 면의 **1.3배** |

브랜드 컬러 외 콘텐츠 연계 컬러가 필요하면 반드시 배경 컬러와의 조화를 고려한다.

## 6. 비주얼 에셋 (8.0) — 전단지에서 사용 가능한 아이콘 · 일러스트

> **가이드에 제공된 데이터만 사용한다.** 외부 아이콘·일러스트·스톡 이미지 사용 불가.

### 6.1 라인 아이콘 (8.1 ~ 8.2)

T-B 로고의 직선·곡선·사선 특징에서 파생. 1 line Stroke / Round Corner / Diagonal Shape / Straight Shape.

| 항목 | 규정 |
|---|---|
| Design Area | 16 dp × 16 dp (정방형 비율 유지 원칙) |
| Padding Area | 상하좌우 2 dp **반드시 확보** |
| Total Area | 20 dp × 20 dp |
| 선 굵기 / 사선 각도 | **0.85 dp / 120°** |
| 컷팅 간격 | 선 굵기와 동일 여백 |
| 조형 Rule | Rule 1 우선 (직선→사선 한 라인 연결), Rule 2·3은 차선 |
| 복수 오브젝트 조합 | 조합 오브젝트는 **우측 하단**에 일관 배치. Round / Object 2타입 |

**카테고리**: Service(홈·메뉴·설정·로그인·챗봇·B다이렉트샵·B world·B 포인트·B 캐쉬 등) · Product(B tv air, AI 5, AI 4 vision, Smart 3, 기가 와이파이, 윙즈, 500M/100M/1.7G 인터넷 등) · Telco · Electronics · Benefit(쿠폰·할인·선물·경품·포인트·1+1·FREE·무제한·VIP 등) · Business · Technology · People · Object · Location · Transportation · Action · Life Style

### 6.2 2D 아이콘 (8.3 ~ 8.5)

플랫 기반 + 입체감. 원 규정 문구는 **오렌지·핑크 컬러**로 생동감 표현이나, 2026-09-17 BX 확인 결과
실제 제작·배포된 에셋 10종은 전부 **B Blue 계열**이다 — 오렌지·핑크 버전은 없다. B Blue 버전을
그대로 등재해 쓴다([assets-line-icon.md](assets-line-icon.md)). 확장형은 메인 아이콘 중심에
주제 연관 오브젝트를 리듬감 있게 배치.

### 6.3 2.5D 아이콘 (8.6 ~ 8.7)

디테일한 그라디언트 + 아이소메트릭. **메인 오브젝트 B Blue**, 보조 오브젝트는 서브·3차 서브 컬러. 오브젝트 고유 컬러가 필요한 경우 예외 적용 가능하되 B Blue와의 조화 고려.

### 6.4 3D 아이콘 (8.8 ~ 8.9)

생성형 AI로 스타일 구축 후 후보정. 원칙: Realistic Material / Vibrant Mood / Soft Contrast / No Excessive Perspective.
