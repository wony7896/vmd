# 제품 포토그래피 인덱스 — 단말기

> 원본 폴더: `../brand guide/Product Photography/` · 파일 22개
> 규정: [brand.md](brand.md) **7.0 제품 포토그래피** — 3D 아이콘(6.4)과 다른 규정을 따른다
> 갱신 2026-09-17 · UUID 파일 8개 기종 확인 완료(삼성·애플 공식 색상 대조), 파일명 교체

## 왜 아이콘과 분리하는가

| | 3D 아이콘 | 제품 포토그래피 |
|---|---|---|
| 성격 | 브랜드 전용 일러스트 | 실제 단말기 촬영·렌더 |
| 규정 | brand.md 6.4 | brand.md 7.0 |
| 갱신 | 사실상 고정 | **모델 출시마다 교체** |
| 포맷 | PNG 투명 | webp · avif · png 혼재 |

> 단말기는 **출시·단종에 따라 통째로 바뀐다.** 아이콘과 같은 문서에 두면 갱신할 때마다 아이콘 목록까지 흔들린다.

## 사용 규칙

1. 단종 모델을 전단지에 쓰지 않는다. **사용 전 현재 판매 라인업을 확인한다.**
2. 기종명을 전단지에 표기할 때는 정식 명칭을 쓴다. 이 표의 '기종'은 **식별용 메모지 공식 표기가 아니다.**
3. 포맷이 섞여 있다. 인쇄물에는 `.avif`·`.webp`가 처리되지 않는 워크플로가 있으므로 PNG 변환이 필요할 수 있다.
4. **검색어** 열로 찾는다. 기종명·별칭·폼팩터가 들어 있다 — `갤럭시Z플립7`·`플립7`·`접는폰`이 같은 파일에 걸린다.
5. 제품컷은 **`3. 요금 안내 + 상품`** 블록의 후보다 ([template.md](template.md) 2.5). 다른 블록에는 자동으로 붙지 않는다.
