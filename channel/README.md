# 채널표 스튜디오

B tv · B tv pop · B tv cable **방송 채널 안내(채널표)** A4 양면을 채널 데이터에서 자동으로 짜는 도구.
저장소 루트의 `channel-studio.html` 하나를 브라우저로 열면 동작한다(서체·로고·데이터가 파일 안에 있다).

## 화면에서 하는 일

- **상품·판 고르기** — 원본 6개 판(B tv 2023-08/11/12, pop 2023-08/11, cable 2023-11)이 들어 있다.
- **채널 표 고치기** — 번호·채널명·티어·장르를 고치면 앞·뒷면이 바로 다시 짜인다.
  앞면은 티어별, 뒷면은 장르별로 5단 세로 우선 배치하고, 줄 높이를 쪽에 맞춰 자동으로 줄인다.
  넘치는 채널명은 가로로만 좁힌다.
- **머리 숫자 자동** — "N개 전 채널" 은 티어별 누적 수를 세어 채운다. 손으로 고치다 틀릴 일이 없다.
- **점검** — 번호 겹침, 앞·뒷면 어디에도 안 나오는 채널, 너무 작아진 글자를 알려준다.
- **지난 판과 비교** — 추가·종료·번호·티어·장르·이름 변경을 뽑아 준다. 수정 요청서와 대조할 때 쓴다.
- **새 판** — 지금 판을 복사해 다음 달 판을 만든다. 고친 내용은 그 브라우저에만 저장되므로 나눌 때는 CSV로 내보낸다.
- **PDF 저장** — 브라우저 인쇄(A4, 여백 없음)로 두 쪽 PDF를 만든다.

## 파일

| | |
|---|---|
| `channels.csv` | 데이터 원본. 상품·기준·티어·번호·채널명·장르·뒷면표기 |
| `src.html` | 화면 원본 |
| `build.py` | `src.html` + `channels.csv` + 서체·로고 → `../channel-studio.html`. 판별 날짜·가격·안내문은 이 파일의 `META` |
| `extract/` | 2023년 원본(PDF·.ai·수정요청 pptx)에서 `channels.csv` 를 처음 뽑은 스크립트. 원본 파일은 프로젝트 공유 폴더 `채널표/` 에 있고 저장소에는 없다 |

```bash
python3 channel/build.py          # 다시 만들기
python3 channel/build.py --check  # 번들이 원본과 어긋나는지만 확인
```

**`channels.csv` 와 `src.html` 이 원본이고 `channel-studio.html` 은 생성물이다.**

## 원본 데이터에 대해

- 8월판은 PDF에서 글자를 그대로 뽑았다. 11월 pop·cable .ai 는 글자가 윤곽선이라 눈으로 옮겨 적었다
  (`extract/nov_transcribed.py`). 채널 수는 원본 머리 숫자와 모두 맞췄지만 철자는 한두 개 틀릴 수 있다.
- B tv 11월판은 12월 수정요청 pptx 에 붙은 이미지에서 8월판과의 차이를 읽어 만들었다.
- B tv 12월판은 11월판에 12월 수정요청을 적용한 **미확정본**이다.
- 원본 쪽 오타 두 곳: B tv 11월 미니 59 → 실제 60, 12월 요청서 스탠다드 232 → 계산상 233.
